# 機能一覧

本ドキュメントは [01_overview.md](./01_overview.md)〜[04_auth_and_authorization.md](./04_auth_and_authorization.md)
で確定している設計内容をもとに、操作ユーザー種別（園側 / 保護者側）ごとに機能を整理したものである。
未確定の仕様（価格設定方式、返金ポリシー、通知機能等）は含めず、[06_open_questions.md](./06_open_questions.md)
側で管理する。

## 1. 園（保育園・幼稚園）側の機能

園スタッフ（`kindergarten_staff`、role: `owner` / `staff`）が利用する機能。
初回の園開設は公開登録ではなく、運営者による Laravel command で行う。

### 1.1 アカウント・認証

| 機能 | 内容 |
|---|---|
| ログイン | JWT認証（`tymon/jwt-auth`）。アクセストークン+リフレッシュトークン方式。`auth:staff` guardで保護者側と分離 |
| テナントスコープ | 自園（`kindergarten_id`）のデータのみ操作可能。Global Scopeで自動適用 |
| 権限ロール | `owner` は園設定・Stripe・スタッフ管理を実行可能。`staff` は日常運用系機能を担当 |
| staff 招待 | `owner` が追加スタッフを招待し、招待されたスタッフは初回パスワード設定後に利用開始 |

### 1.2 園児管理

| 機能 | 内容 |
|---|---|
| 園児登録・編集 | 氏名、クラス（`class_name`）を登録 |
| 在籍状況管理 | 在園中 / 卒園 / 退園（`status`）の管理 |

### 1.3 保護者招待・紐づけ管理

| 機能 | 内容 |
|---|---|
| 招待QRコード発行 | 園児1人につきラベル（父用・母用等）を指定して複数枚発行可能。詳細: [03_invitation_flow.md §1](./03_invitation_flow.md) |
| 招待の印刷用出力 | QRコードをPDF/印刷用画面として出力 |
| 招待の失効 | 紛失・誤発行時に招待を手動で無効化（`revoked_at`） |
| 招待の再発行 | 失効・期限切れの招待に対し、同一園児に新しい招待を再発行 |
| 紐づけ済み保護者一覧確認 | 園児詳細画面から、紐づいている保護者を一覧表示 |
| 紐づけ解除 | 卒園・誤登録対応として保護者と園児の紐づけを解除（論理削除、確認モーダル必須）。詳細: [03_invitation_flow.md §5](./03_invitation_flow.md) |
| 紐づけ復元（再紐づけ） | 誤操作による解除を一定期間内であれば取り消し可能 |

### 1.4 アルバム・写真管理

| 機能 | 内容 |
|---|---|
| アルバム作成 | イベント日（`event_date`）を紐づけてアルバムを作成 |
| 写真アップロード | オリジナル画像を保存し、非同期でプレビュー（透かし入り・低解像度）を自動生成 |
| 写真への園児タグ付け | 1枚の写真に複数の園児をタグ付け（多対多）。当面は手動作業を想定 |
| 価格設定 | 写真ごとに販売価格（`price`）を設定 |

### 1.5 決済・入金設定

| 機能 | 内容 |
|---|---|
| Stripe Connectオンボーディング | 管理画面からStripeの本人確認・銀行口座登録に遷移し、園専用の入金先アカウントを取得 |
| オンボーディング状況に応じた販売制御 | オンボーディング未完了の園は、保護者向けの購入導線が無効化される |

## 2. 保護者側の機能

保護者（`guardians`）が利用する機能。

### 2.1 アカウント登録・認証

| 機能 | 内容 |
|---|---|
| 招待QRからの新規登録 | QRコード読込 → 招待内容（園児名・園名等）を確認 → メール/パスワードで新規登録。詳細: [03_invitation_flow.md §2](./03_invitation_flow.md) |
| ログイン | JWT認証（`tymon/jwt-auth`）。アクセストークン+リフレッシュトークン方式。`auth:guardian` guardで園側と分離 |
| メールアドレス確認 | なりすまし登録抑止のためメール確認を実施 |

### 2.2 園児との紐づけ

| 機能 | 内容 |
|---|---|
| 兄弟姉妹の追加紐づけ | ログイン済みの状態で別の園児の招待QRを読み込み、既存アカウントに追加で紐づけ。詳細: [03_invitation_flow.md §3](./03_invitation_flow.md) |
| 複数園児の一元管理 | 1アカウントに複数園児（兄弟姉妹）を紐づけて閲覧・購入可能 |

### 2.3 写真閲覧

| 機能 | 内容 |
|---|---|
| 写真一覧・プレビュー閲覧 | 自分に有効に紐づいている園児が写っている写真のみを一覧表示（プレビュー画像）。詳細: [04_auth_and_authorization.md §4](./04_auth_and_authorization.md) |
| アクセス制御 | 他の園児のみが写る写真は一覧・詳細ともに取得不可（クエリレベルで絞り込み） |

### 2.4 購入・ダウンロード

| 機能 | 内容 |
|---|---|
| 写真購入 | Stripe Checkoutを通じて写真を購入 |
| 購入済み写真のダウンロード | 購入後、有効期限付き署名URLでオリジナル画像（透かしなし・高解像度）を取得 |
| 解除後の購入済みコンテンツへのアクセス継続 | 園児との紐づけが解除された後も、解除前に購入済みの写真は引き続きダウンロード可能 |
